## 1. 项目定位

从零构建一个类 Claude Code 的 **Coding Agent**（终端交互、可行动、长程、可约束、可回溯、可量化），以学习与实践为目标。

- **方法论**：以 Claude Code / MewCode 最佳实践为参考蓝本，融入个人深化设计（工具结果在线压缩、长任务 Harness 四方案、OpenClaw/ClaudeCode 记忆对比）。
- **核心公式**：`Agent = LLM + runtime + Harness`。LLM 提供智能，runtime 提供可交互的软件基础，Harness 通过规则与约束为不确定性赋予可靠性与稳定性。
- **第一性原理**：上下文窗口的生命周期贯穿 Agent 设计——消息格式、LLM 响应、工具调用、上下文压缩、记忆系统，都以「上下文」为时序线索。

## 2. 架构骨架

### 2.1 一条横切线索 + 三条主线

- **横切线索**：上下文工程（前缀缓存保护、append-only、动态更新、三层压缩）——单独成章（`01`），被记忆/工具/可观测性共同引用。
- **三条主线**：记忆系统、工具能力、可观测性。三条主线高内聚、依赖清晰，共同覆盖完整 Agent 的关键设计；可观测性是功能无关但开发必需的工程旁路。

### 2.2 支撑板块

- **评估体系**（`11`）：编码能力 + 工具调用能力双维度；主基准 SWE-bench-Live，辅助 BFCL/τ-Bench。评估度量一切改进的效果。
- **交互设计**（`05`）：Textual TUI，与可观测性结合（实时活动流/指标）。
- **Harness 整合**（`12`）：测试驱动闭环、检查点反思、约束校验与失败恢复、规则量化追踪。
